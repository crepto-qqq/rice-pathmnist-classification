# COMP5318 Machine Learning and Data Mining

This repository contains the group work for COMP5318 assignments.

## Repository Structure

- [`A1/`](A1/README.md): Assignment 1 - Rice Classification
- [`A2/`](A2/README.md): Assignment 2 - PathMNIST Image Classification

Each assignment keeps its own specification, notebook, documentation, data
instructions, and dependencies. Local environments, large datasets, trained
models, checkpoints, and IDE settings are excluded from version control.

## Collaboration

Work on a feature branch and merge reviewed changes into `main`. Keep changes
inside the relevant assignment directory and avoid committing generated files.
